# Verification evaluation: task

Each file `situation_*.py` below contains a behavior model. For each one:

1. Run verification (`verify(model)` with the default profile).
2. Explain each blocking finding in two or three sentences.
3. Do what the verification skill says: change the model, report a finding, or both. Write the
   changed model to `situation_N_after.py`, and your explanation to `situation_N.md`.

Do not change what the domain requires: each file's docstring states the domain rules, and they
are not negotiable.
