# Application evaluation: task

Build a small **order intake service** in Python on the pinned Behavior release.

- Model: customers (name, credit limit in money with two decimals) and orders (customer, amount,
  status open or closed). Placing an order must keep the customer's open orders within the credit
  limit. An order can be closed.
- Service: a module `service.py` with functions `place_order(customer_id, amount)` and
  `close_order(order_id)`. They return the decision result and reasons, and persist every
  allowed change. Order ids are generated by the service (for example with `uuid4`).
- Storage: a backend of your own that keeps documents in a SQLite file (`store.db`), used by the
  service.
- Tests: `test_service.py`, covering an allowed order, an order refused by the credit limit, two
  concurrent placements of which only one can succeed, and a restart that reopens the same store
  and replays its history.

Use only the installed `behavior` package and the Behavior skills.
